# CS2MarketUZ brand imagery

- `cs2marketuz-avatar.png` — 512 × 512 PNG for the Telegram bot profile image. Upload it manually through BotFather; the bot cannot change its own profile photo.
- `cs2marketuz-start.png` — 1200 × 630 PNG start-message artwork. The `/start` handler sends this image with the existing language selector or welcome message.
- Matching SVG source files are included for scalable editing.
- Skin-card images are not generated or substituted with mock artwork. The Mini App continues to use the actual image URLs from the current market/catalog cache and its neutral placeholder when a listing has no image. Wear labels are shown only when the skin name contains a known wear; float values are not in the current API data.

Before publishing, replace the artwork with approved brand assets if needed and upload the avatar in BotFather. Telegram profile images should be square; keep the logo centered and legible at small sizes. The banner is composed to display at a 1200:630 (1.91:1) landscape ratio.
